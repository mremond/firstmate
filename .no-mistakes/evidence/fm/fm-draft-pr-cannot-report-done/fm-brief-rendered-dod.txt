===== brief.md for --mode no-mistakes: Delivery contract section =====
1:Delivery contract: mode=no-mistakes
3:When you believe it is complete, append `done [at=<epoch>]: {summary}` to the status file and stop.
31:After /no-mistakes reports CI green (the CI-ready return point - do not wait for it to keep monitoring in the background until merge), read the PR back from the forge and confirm it is not a draft (`gh pr view <url> --json isDraft` must print false); if it is a draft, mark it ready with `gh-axi pr ready`.
32:A draft cannot be merged, so a done report on one leaves the merge unasked.
33:Then append `done [at=<epoch>]: PR {url} checks green` and stop. You are finished.
34:If you deliberately keep the PR a draft, append `paused [at=<epoch>]: {why the draft is held}` instead of done.
===== brief.md for --mode direct-PR: Delivery contract section =====
1:Delivery contract: mode=direct-PR
4:When it is implemented and committed, push your branch and open a PR with `gh-axi` that is ready for review, not a draft.
5:Before you report done, read the PR back from the forge and confirm it is not a draft (`gh pr view <url> --json isDraft` must print false); if it is a draft, mark it ready with `gh-axi pr ready`.
6:A draft cannot be merged, so a done report on one leaves the merge unasked.
7:Then append `done [at=<epoch>]: PR {url}` to the status file and stop.
8:If you deliberately keep the PR a draft, append `paused [at=<epoch>]: {why the draft is held}` instead of done.
